# صور المنتجات

كل منتج في `data/products.ts` يشير إلى صورة هنا عبر `require` ثابت، مثال:

```ts
image: require("../assets/images/tea-time-ice-tea-peach-330ml.png")
```

## كيف تستبدل الصور بصورك؟

1. جهّز صورة المنتج بصيغة **PNG** (يُفضّل خلفية شفافة ومقاس مربّع مثل 600×600).
2. استبدل الملف الموجود هنا بنفس **اسم الملف بالضبط** (لا تغيّر الاسم).
3. أعد تشغيل خادم Expo إذا كان يعمل (`npx expo start -c` لمسح الذاكرة المؤقتة).

> الصور الحالية مجرّد صور بديلة (placeholder) ملوّنة حسب التصنيف، استبدلها بصورك.

## إضافة منتج جديد بصورة جديدة

1. ضع صورة المنتج هنا، مثلاً `my-new-drink.png`.
2. أضف عنصراً جديداً في `data/products.ts` مع:
   ```ts
   image: require("../assets/images/my-new-drink.png"),
   ```
   ⚠️ يجب أن يكون مسار `require` نصاً ثابتاً صريحاً (لا تبنِه من متغيّر)
   لأن حزمة Metro تحتاج مساراً معروفاً وقت البناء.
